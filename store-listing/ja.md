# 日本語 (ja)

## Name

```
Advanced Bookmarks – あいまい検索でフォルダ選択
```

## Summary

```
ブックマーク保存ダイアログをあいまい検索で高速化。数文字入力するだけで入れ子のフォルダをすぐに見つけられます。
```

## Detailed description

```
Chrome 標準のブックマーク保存ダイアログは、これまでに作成したすべてのフォルダを 1 つのフラットなプルダウンに並べます。フォルダが少し増えただけで、ページの保存はスクロールして探す作業になります。

Advanced Bookmarks は、そのダイアログを「入力できる」ダイアログに置き換えます。

フォルダのあいまい検索
入力を始めると、フォルダの一覧がその場で絞り込まれます。入力した文字は順番どおりに含まれていればよく、連続している必要も、単語の先頭である必要もありません。「wpr」と入力すれば「Work Projects」「Weekly Prep」「WordPress」が見つかります。絞り込みはフォルダ名だけでなくフルパスにも効くので、親フォルダ名を入力してその配下だけに絞ることもできます。一致した文字はハイライトされ、各候補にはパンくず表示（ブックマーク バー › Work › Projects）が付くため、どのフォルダを選ぼうとしているかが常に分かります。

賢い初期選択
• ページタイトルを読み取り、最も近いフォルダをあらかじめ選択します。ポップアップを開いた時点で目的のフォルダが選ばれていることがよくあります
• 直前に保存したフォルダが一覧の先頭に並ぶため、同じフォルダへ続けて保存する場合はキー 1 つで済みます

すべてキーボードで操作
ショートカットで開き、入力して絞り込み、矢印キーで移動、Enter で保存、Esc で中止。ダイアログを開いた瞬間にフォルダ欄へフォーカスが当たるので、すぐに入力を始められます。Ctrl+D はブラウザ側で予約されており拡張機能から変更できないため、既定では Alt+D を提案しています。chrome://extensions/shortcuts で空いている任意の組み合わせに変更できます。

そのほかの機能
• ダイアログ内から新しいフォルダを作成し、保存先をツリー全体から選択
• すでにブックマーク済みのページは編集モードで開き、現在のフォルダが選択された状態になります
• ダイアログを離れずにブックマークを削除
• 日本語・英語・フランス語・ドイツ語・スペイン語・ポルトガル語・中国語に対応

プライバシー
トラッキングなし、解析なし、ネットワーク通信なし、アカウント不要、サードパーティ製ライブラリなし。動作に必要な権限は 2 つだけです。
• bookmarks — フォルダツリーの読み取りと、ブックマークの作成・更新・移動・削除
• tabs — フォームに初期値を入れるため、現在のページのタイトルと URL を読み取り

データがブラウザの外に出ることは一切ありません。本拡張機能は MIT ライセンスのオープンソースで、依存関係のない数百行の JavaScript です。内容はご自身で確認できます。
https://github.com/bcollard/chrome-advanced-bookmarks
```
