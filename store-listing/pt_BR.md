# Português do Brasil (pt_BR)

## Name

```
Advanced Bookmarks – Busca difusa de pastas
```

## Summary

```
Gerenciador de favoritos com busca difusa: digite algumas letras e encontre qualquer pasta aninhada na hora.
```

## Detailed description

```
A janela de favoritos do Chrome mostra uma lista suspensa plana com todas as pastas que você já criou. Passando de algumas poucas pastas, salvar uma página vira rolagem e caça.

O Advanced Bookmarks troca essa janela por uma em que você pode digitar.

BUSCA DIFUSA DE PASTAS
Comece a digitar e a lista de pastas vai filtrando. As letras digitadas só precisam aparecer na ordem — não precisam estar juntas nem começar a palavra. Digitar "prw" encontra "Projetos Web", "Prensa Semanal" e "Protótipos Wireframe". O filtro vale para o nome da pasta e para o caminho completo, então dá para digitar o nome de uma pasta superior para restringir às subpastas dela. Os caracteres correspondentes ficam destacados e cada resultado mostra o caminho (Barra de favoritos › Trabalho › Projetos), para você sempre saber qual pasta está prestes a escolher.

PADRÕES INTELIGENTES
• A janela lê o título da página e pré-seleciona a pasta que mais combina, então muitas vezes a pasta certa já está escolhida ao abrir
• A última pasta usada sobe para o topo da lista, o que reduz a uma tecla cada gravação de uma sequência na mesma pasta

TUDO PELO TECLADO
Abra com o seu atalho, digite para filtrar, setas para navegar, Enter para salvar, Esc para sair. O campo Pasta recebe o foco assim que a janela abre, então dá para digitar na hora. O Chrome reserva Ctrl+D no nível do navegador e nenhuma extensão pode substituí-lo, por isso Alt+D é o sugerido — remapeie para qualquer combinação livre em chrome://extensions/shortcuts.

TAMBÉM INCLUI
• Crie uma pasta nova dentro da própria janela e escolha o local na árvore completa
• Páginas já favoritadas abrem em modo de edição, com a pasta atual pré-selecionada
• Remova um favorito sem sair da janela
• Interface disponível em português, inglês, francês, alemão, espanhol, japonês e chinês

PRIVACIDADE
Sem rastreamento, sem analytics, sem requisições de rede, sem conta, sem bibliotecas de terceiros. Duas permissões, ambas necessárias para funcionar:
• bookmarks — ler sua árvore de pastas e criar, atualizar, mover ou excluir favoritos
• tabs — ler o título e a URL da página atual para preencher o formulário

Nada sai do seu navegador. A extensão é de código aberto sob a licença MIT e tem algumas centenas de linhas de JavaScript sem dependências, então você pode verificar tudo:
https://github.com/bcollard/chrome-advanced-bookmarks
```
