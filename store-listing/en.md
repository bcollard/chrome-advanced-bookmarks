# English (en) — default locale

## Name

```
Advanced Bookmarks – Fuzzy Folder Search
```

## Summary

```
Bookmark dialog with fuzzy folder search: type a few letters to find any nested bookmark folder and save the page instantly.
```

## Category

**Tools** — where the item already sits. A bookmark dialog is a utility, not a
planning app. The category is global, not per-locale: set it once.

## Detailed description

```
Chrome's built-in bookmark dialog gives you one flat dropdown containing every folder you have ever created. Past a handful of folders, saving a page turns into scrolling and hunting.

Advanced Bookmarks replaces that dialog with one you can type into.

FUZZY FOLDER SEARCH
Start typing and the folder list narrows as you go. The letters you type only have to appear in order — they do not have to be next to each other, and they do not have to start the word. Typing "wpr" finds "Work Projects", "Weekly Prep" and "WordPress". Matching runs against the folder name and against its full path, so you can type a parent folder's name to narrow down its children. Matched characters are highlighted, and every result carries its breadcrumb trail (Bookmarks Bar › Work › Projects) so you always know which folder you are about to pick.

SMART DEFAULTS
• The dialog reads the page title and pre-selects the folder that matches it best, so the right folder is often already chosen when the popup opens
• The folder you saved into most recently is ranked to the top, which turns a run of saves into the same folder into one keystroke each

FULL KEYBOARD CONTROL
Open with your shortcut, type to filter, arrow keys to move, Enter to save, Escape to back out. The folder field takes focus the moment the dialog opens, so you can start typing straight away. Chrome reserves Ctrl+D at the browser level and no extension can override it, so Alt+D is suggested instead — rebind it to any free combination at chrome://extensions/shortcuts.

ALSO INCLUDED
• Create a new folder from inside the dialog and choose its parent from the full tree
• Pages you have already bookmarked open in edit mode with their current folder pre-selected
• Remove a bookmark without leaving the dialog
• Interface available in English, French, German, Spanish, Portuguese, Japanese and Chinese

PRIVACY
No tracking, no analytics, no network requests, no account, no third-party libraries. Two permissions, both required to do the job:
• bookmarks — read your folder tree and create, update, move or delete bookmarks
• tabs — read the current page's title and URL to pre-fill the form

Nothing ever leaves your browser. The extension is open source under the MIT license and is a few hundred lines of dependency-free JavaScript, so you can verify all of this yourself:
https://github.com/bcollard/chrome-advanced-bookmarks
```
