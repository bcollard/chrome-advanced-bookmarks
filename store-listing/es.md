# Español (es)

## Name

```
Advanced Bookmarks – Búsqueda difusa de carpetas
```

## Summary

```
Gestor de marcadores con búsqueda difusa: escribe unas letras y encuentra cualquier carpeta anidada al instante.
```

## Detailed description

```
El cuadro de diálogo de marcadores de Chrome muestra una lista desplegable plana con todas las carpetas que has creado. Pasadas unas pocas carpetas, guardar una página se convierte en desplazarse y buscar.

Advanced Bookmarks sustituye ese diálogo por uno en el que puedes escribir.

BÚSQUEDA DIFUSA DE CARPETAS
Empieza a escribir y la lista de carpetas se filtra sobre la marcha. Las letras que escribes solo tienen que aparecer en orden: no hace falta que estén juntas ni que empiecen la palabra. Escribir "prw" encuentra "Proyectos Web", "Prensa Semanal" y "PrestaShop Widgets". El filtrado se aplica al nombre de la carpeta y a su ruta completa, así que puedes escribir el nombre de una carpeta superior para acotar sus subcarpetas. Los caracteres coincidentes aparecen resaltados y cada resultado muestra su ruta (Barra de marcadores › Trabajo › Proyectos), de modo que siempre sabes qué carpeta estás a punto de elegir.

VALORES PREDETERMINADOS INTELIGENTES
• El diálogo lee el título de la página y preselecciona la carpeta que mejor encaja, así que a menudo la carpeta correcta ya está elegida al abrirse
• La última carpeta en la que guardaste sube al principio de la lista, lo que reduce a una sola pulsación cada guardado de una serie en la misma carpeta

TODO CON EL TECLADO
Abre con tu atajo, escribe para filtrar, flechas para moverte, Intro para guardar, Escape para salir. El campo Carpeta recibe el foco nada más abrirse, así que puedes escribir de inmediato. Chrome reserva Ctrl+D a nivel de navegador y ninguna extensión puede sustituirlo, por eso se sugiere Alt+D; puedes reasignarlo a cualquier combinación libre en chrome://extensions/shortcuts.

TAMBIÉN INCLUYE
• Crea una carpeta nueva desde el propio diálogo y elige su ubicación en el árbol completo
• Las páginas ya guardadas se abren en modo edición, con su carpeta actual preseleccionada
• Elimina un marcador sin salir del diálogo
• Interfaz disponible en español, inglés, francés, alemán, portugués, japonés y chino

PRIVACIDAD
Sin seguimiento, sin analíticas, sin peticiones de red, sin cuenta, sin bibliotecas de terceros. Dos permisos, ambos necesarios para funcionar:
• bookmarks — leer tu árbol de carpetas y crear, actualizar, mover o eliminar marcadores
• tabs — leer el título y la URL de la página actual para rellenar el formulario

Nada sale nunca de tu navegador. La extensión es de código abierto con licencia MIT y son unos cientos de líneas de JavaScript sin dependencias, así que puedes comprobarlo tú mismo:
https://github.com/bcollard/chrome-advanced-bookmarks
```
