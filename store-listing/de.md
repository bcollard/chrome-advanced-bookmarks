# Deutsch (de)

## Name

```
Advanced Bookmarks – Unscharfe Ordnersuche
```

## Summary

```
Lesezeichen-Dialog mit unscharfer Suche: ein paar Buchstaben genügen, um jeden verschachtelten Ordner zu finden.
```

## Detailed description

```
Chromes eingebauter Lesezeichen-Dialog zeigt eine flache Liste mit sämtlichen Ordnern, die Sie je angelegt haben. Ab einer Handvoll Ordner wird das Speichern einer Seite zum Scrollen und Suchen.

Advanced Bookmarks ersetzt diesen Dialog durch einen, in den Sie tippen können.

UNSCHARFE ORDNERSUCHE
Tippen Sie los, und die Ordnerliste filtert sich mit. Die eingegebenen Buchstaben müssen lediglich in der richtigen Reihenfolge vorkommen — sie müssen weder nebeneinander stehen noch das Wort beginnen. "arp" findet "Arbeit Projekte", "Archiv Presse" und "Artikel Prototypen". Gefiltert wird sowohl nach dem Ordnernamen als auch nach dem vollständigen Pfad, Sie können also den Namen eines übergeordneten Ordners eingeben, um dessen Unterordner einzugrenzen. Übereinstimmende Zeichen werden hervorgehoben, und jedes Ergebnis zeigt seinen Pfad (Lesezeichenleiste › Arbeit › Projekte), damit Sie immer wissen, welchen Ordner Sie gleich wählen.

INTELLIGENTE VORAUSWAHL
• Der Dialog liest den Seitentitel und wählt den am besten passenden Ordner vor — der richtige Ordner ist beim Öffnen also oft schon gesetzt
• Der zuletzt verwendete Ordner steht ganz oben, wodurch mehrere Speichervorgänge in denselben Ordner jeweils nur einen Tastendruck kosten

VOLLSTÄNDIG ÜBER DIE TASTATUR
Mit Ihrem Kürzel öffnen, tippen zum Filtern, Pfeiltasten zum Navigieren, Enter zum Speichern, Escape zum Abbrechen. Das Ordnerfeld erhält beim Öffnen den Fokus, Sie können also sofort tippen. Chrome reserviert Strg+D auf Browserebene und keine Erweiterung kann das überschreiben — deshalb wird Alt+D vorgeschlagen. Unter chrome://extensions/shortcuts lässt sich das auf jede freie Kombination umlegen.

AUSSERDEM
• Neuen Ordner direkt im Dialog anlegen und seinen Speicherort im gesamten Baum auswählen
• Bereits gespeicherte Seiten öffnen sich im Bearbeitungsmodus mit vorausgewähltem aktuellen Ordner
• Lesezeichen entfernen, ohne den Dialog zu verlassen
• Oberfläche verfügbar auf Deutsch, Englisch, Französisch, Spanisch, Portugiesisch, Japanisch und Chinesisch

DATENSCHUTZ
Kein Tracking, keine Analyse, keine Netzwerkanfragen, kein Konto, keine Fremdbibliotheken. Zwei Berechtigungen, beide für die Funktion erforderlich:
• bookmarks — den Ordnerbaum lesen sowie Lesezeichen anlegen, ändern, verschieben oder löschen
• tabs — Titel und URL der aktuellen Seite lesen, um das Formular vorauszufüllen

Nichts verlässt jemals Ihren Browser. Die Erweiterung ist quelloffen unter der MIT-Lizenz und besteht aus einigen hundert Zeilen JavaScript ohne Abhängigkeiten — Sie können all das selbst überprüfen:
https://github.com/bcollard/chrome-advanced-bookmarks
```
