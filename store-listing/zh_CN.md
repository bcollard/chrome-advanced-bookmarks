# 简体中文 (zh_CN)

## Name

```
Advanced Bookmarks – 书签文件夹模糊搜索
```

## Summary

```
书签保存对话框，支持模糊搜索：输入几个字母即可找到任意多层嵌套的书签文件夹并立即保存。
```

## Detailed description

```
Chrome 自带的书签保存对话框，会把你创建过的所有文件夹平铺在一个下拉列表里。文件夹稍微多一点，保存网页就变成了滚动和翻找。

Advanced Bookmarks 把这个对话框换成一个可以直接输入的对话框。

文件夹模糊搜索
开始输入，文件夹列表就随之收窄。你输入的字母只需按顺序出现即可，不必相邻，也不必位于词首。输入 "wpr" 就能找到 "Work Projects"、"Weekly Prep" 和 "WordPress"。匹配同时作用于文件夹名称和它的完整路径，因此你可以输入上级文件夹的名字来缩小到它的子文件夹。匹配到的字符会高亮显示，每条结果都带有路径面包屑（书签栏 › Work › Projects），你始终清楚自己将要选中哪个文件夹。

智能默认值
• 对话框会读取网页标题并预选最匹配的文件夹，弹窗打开时往往已经选中了正确的目标
• 最近一次保存过的文件夹会排在列表最前，连续保存到同一个文件夹时每次只需按一下键

完全键盘操作
用你的快捷键打开，输入以筛选，方向键移动，Enter 保存，Esc 退出。对话框打开时焦点即在文件夹输入框，可以立刻开始输入。Ctrl+D 由浏览器保留，扩展程序无法覆盖，因此默认建议使用 Alt+D；你可以在 chrome://extensions/shortcuts 改成任意空闲组合。

其他功能
• 在对话框内直接新建文件夹，并从完整目录树中选择它的位置
• 已加入书签的页面会以编辑模式打开，并预选其当前所在文件夹
• 无需离开对话框即可删除书签
• 界面支持简体中文、英语、法语、德语、西班牙语、葡萄牙语和日语

隐私
无跟踪、无统计分析、无网络请求、无需账号、无第三方库。仅需两项权限，且都是功能所必需：
• bookmarks — 读取文件夹目录树，以及创建、修改、移动或删除书签
• tabs — 读取当前页面的标题和网址，用于预填表单

任何数据都不会离开你的浏览器。本扩展基于 MIT 许可证开源，仅有几百行无依赖的 JavaScript，你可以自行核实：
https://github.com/bcollard/chrome-advanced-bookmarks
```
