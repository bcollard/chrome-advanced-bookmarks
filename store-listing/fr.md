# Français (fr)

## Name

```
Advanced Bookmarks – Recherche floue de dossiers
```

## Summary

```
Gestionnaire de favoris avec recherche floue : tapez quelques lettres pour trouver n'importe quel dossier imbriqué.
```

## Detailed description

```
La fenêtre d'ajout de favori de Chrome affiche une liste déroulante plate contenant tous les dossiers que vous avez créés. Passé une poignée de dossiers, enregistrer une page revient à faire défiler et chercher.

Advanced Bookmarks remplace cette fenêtre par une fenêtre dans laquelle vous pouvez taper.

RECHERCHE FLOUE DE DOSSIERS
Commencez à taper : la liste des dossiers se filtre au fur et à mesure. Les lettres saisies doivent simplement apparaître dans l'ordre — elles n'ont pas besoin d'être contiguës ni de commencer le mot. Taper « prj » trouve « Projets », « Projets Perso » et « Prototypes Jeux ». Le filtrage porte sur le nom du dossier et sur son chemin complet : vous pouvez donc taper le nom d'un dossier parent pour restreindre la recherche à ses sous-dossiers. Les caractères correspondants sont surlignés et chaque résultat affiche son fil d'Ariane (Barre de favoris › Travail › Projets), pour que vous sachiez toujours quel dossier vous vous apprêtez à choisir.

VALEURS PAR DÉFAUT INTELLIGENTES
• La fenêtre lit le titre de la page et présélectionne le dossier qui lui correspond le mieux : le bon dossier est souvent déjà choisi à l'ouverture
• Le dernier dossier utilisé remonte en tête de liste, ce qui réduit à une seule touche chaque enregistrement d'une série vers le même dossier

TOUT AU CLAVIER
Ouvrez avec votre raccourci, tapez pour filtrer, flèches pour naviguer, Entrée pour enregistrer, Échap pour annuler. Le champ Dossier prend le focus dès l'ouverture : vous pouvez taper immédiatement. Chrome réserve Ctrl+D au niveau du navigateur et aucune extension ne peut le remplacer ; Alt+D est donc proposé par défaut, et vous pouvez le réaffecter à n'importe quelle combinaison libre depuis chrome://extensions/shortcuts.

ÉGALEMENT INCLUS
• Créez un nouveau dossier depuis la fenêtre elle-même et choisissez son emplacement dans l'arborescence complète
• Les pages déjà mises en favori s'ouvrent en mode édition, avec leur dossier actuel présélectionné
• Supprimez un favori sans quitter la fenêtre
• Interface disponible en français, anglais, allemand, espagnol, portugais, japonais et chinois

CONFIDENTIALITÉ
Aucun traçage, aucune statistique, aucune requête réseau, aucun compte, aucune bibliothèque tierce. Deux autorisations, toutes deux nécessaires au fonctionnement :
• bookmarks — lire votre arborescence de dossiers et créer, modifier, déplacer ou supprimer des favoris
• tabs — lire le titre et l'URL de la page active pour préremplir le formulaire

Rien ne quitte jamais votre navigateur. L'extension est open source sous licence MIT et tient en quelques centaines de lignes de JavaScript sans dépendance : vous pouvez tout vérifier vous-même.
https://github.com/bcollard/chrome-advanced-bookmarks
```
